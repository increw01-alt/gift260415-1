# 1장 기획서 — 머니플랜 신규 사이트 (휴대폰결제·소액결제 상품권 구입 문의 안내)

작성일: 2026-11-17 / 강도: full (같은 도메인 상품권재테크.com 의 리뉴얼 + 호스팅 이전)

## 1. 목적
휴대폰결제·소액결제로 상품권을 구입하려는 고객의 문의가 전화·카카오톡·문의 폼 중 하나로 머니플랜에 들어온다.
기존 1페이지 랜딩(현금화 소구, 협회 인증 표기)을 "상품권 구입 안내" 정보 사이트로 교체해 광고심의·오인 위험을 없앤다.

## 2. 누가, 무엇을 검색해서 오는가
- 주요 검색어: 휴대폰결제 상품권 구입, 소액결제 상품권, 상품권 휴대폰 결제, 문화상품권 소액결제 구매, 상품권 종류별 구입 방법
- 첫 화면에서 알아야 하는 것: 어떤 상품권을 어떤 결제수단으로 살 수 있는지, 문의하면 무엇을 안내받는지, 문의 방법 3가지

## 3. 전환 목표
- 목표 행동: 문의 (전화 1800-2434, 카카오톡 채널, 문의 폼 /contact/)
- CTA 위치: 상단 헤더 버튼 / 각 안내 섹션 끝 / 하단 배너 / 우측 하단 플로팅 버튼(전 페이지) / 모바일 하단 고정 바(전화·카카오톡·문의하기)
- 휴대폰결제·소액결제 관련 버튼은 모두 `/contact/?type=mobile-payment` 또는 `?type=micro-payment` 로 연결해 문의 유형을 미리 선택

## 4. 구성 (페이지 8개, 정적 HTML + Tailwind CLI + Pretendard)
| URL | 페이지 | 섹션 순서 |
|---|---|---|
| `/` | 메인 | Hero(이미지 자리+문구+CTA) → 구입 가능한 결제수단·상품권 요약 → 이용 흐름 3단계 → 자주 묻는 질문 3개 → 문의 유도 배너 |
| `/guide/` | 상품권 구입 안내 | 상품권 종류별 안내 → 결제수단별 안내 → 준비할 것 → 문의 CTA |
| `/mobile-payment/` | 휴대폰결제·소액결제 구입 문의 안내 | 어떤 경우에 쓰는지 → 진행 순서 → 유의사항(한도·통신사) → 문의 CTA(유형 미리 선택) |
| `/faq/` | 자주 묻는 질문 | 구입·결제·배송·취소 4묶음 아코디언 |
| `/how-to/` | 이용 안내 | 문의부터 수령까지 흐름, 운영시간, 응답 방식 |
| `/contact/` | 문의하기 | 폼(유형·이름 또는 닉네임·연락처·내용·동의) + 전화·카카오톡 안내 |
| `/privacy/` | 개인정보처리방침 | 표준 조항, 수집 항목은 폼과 일치 |
| `/terms/` | 이용약관 | 표준 조항 |
공통: 헤더(로고 자리·메뉴), 푸터(사업자 정보 플레이스홀더·정책 링크), 플로팅 문의 버튼, 모바일 하단 바, GTM 1회.
서버: Cloudflare Pages Functions `POST /api/inquiry` → D1 `inquiries` 테이블. 검증·honeypot·빈도 제한 포함.
