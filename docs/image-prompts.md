# 이미지 생성 프롬프트 — 머니플랜 신규 사이트

작성 2026-11-17 / 팀장. 같은 날 저녁 재욱님 지시로 자사 이미지 에셋(Desktop/이미지/06_웹사이트·앱/사이트_이미지에셋(2025-10~2026-07))을 먼저 반영했다: 히어로·휴대폰결제 히어로 = `hero-cards.png`(파란 3D 카드), 메인 "상품권 종류" 타일 = `voucher-mobile-set.png`·`voucher-department-set.png`, 구입 안내 카드 = 위 타일 + `voucher-mobile-card.png` + `voucher-google-gift.png`, 공유 이미지 = `og-image.png`(hero-cards 를 남색 배경에 합성, 1200×630, 글자 없음). 아래 프롬프트는 사진형 이미지로 바꾸고 싶을 때 쓴다. 교체할 때는 같은 파일명으로 저장하거나 `src/pages` 의 `<img>` 경로와 width·height 를 함께 바꾼다.

공통 조건
- 이미지 안에 글자·숫자·로고·브랜드명을 넣지 않는다. 문구는 모두 HTML 텍스트로 올린다.
- 로고 자리는 비워 둔다. 협회·기관·결제사·통신사의 로고나 그것을 연상시키는 마크를 그리지 않는다.
- 색: 남색 `#1B2A4A`, 파랑 `#3B82F6`, 밝은 파랑 `#60A5FA`, 바탕 흰색·연회색 `#F8FAFC`. 따뜻한 강조색은 쓰지 않는다.
- 분위기: 차분하고 정돈된 안내 서비스. 과장된 돈·지폐·금화·현금 다발 묘사 금지(현금화로 오인될 수 있다). 카드 번호·바코드가 읽히는 묘사 금지.
- 사람 얼굴은 넣지 않거나, 넣더라도 특정 인물로 보이지 않게 뒷모습·손 위주.
- 파일 형식: WebP 또는 PNG. 저장 후 `width`·`height` 속성을 실제 크기로 적고 첫 화면 밖은 `loading="lazy"`.

반영 순서
1. 생성된 파일을 `public/images/` 에 저장한다 (파일명은 표와 같게).
2. `src/pages/**` 의 해당 `<div role="img" …>` 를 `<img src="/images/파일명" width="…" height="…" alt="…" loading="lazy">` 로 바꾼다. alt 는 내용을 설명하는 한국어 한 문장.
3. `npm run build` → `npm run check` 로 경로·크기 지정 확인.
