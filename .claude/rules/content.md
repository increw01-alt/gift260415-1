# 콘텐츠 작성 규칙

- 검색 의도에 답하는 글을 쓴다. 소제목, 표, 체크리스트, 사례, FAQ 로 내용을 채운다
- 글 개수보다 한 페이지의 내용 밀도와 새로운 정보가 중요하다. 경쟁 페이지보다 본문을 풍부하게 쓴다
- 같은 문장 구조의 반복, 뻔한 도입부와 맺음말을 피한다
- 네이버 블로그와 티스토리에 같은 주제를 올릴 때는 제목·구조·문장을 다르게 쓴다
- 이 사이트의 브랜드 정보만 쓴다. 다른 브랜드의 이름·연락처를 섞지 않는다
- 수익·승인·통과를 보장하는 표현, 근거 없는 수치와 후기를 쓰지 않는다
- 광고 정책상 위험한 표현은 사실적이고 중립적인 표현으로 바꾼다
- 정책·법·가격·서비스 조건처럼 바뀌는 내용은 공식 자료를 확인하고 출처와 확인 시점을 남긴다
- 이미지에는 내용을 설명하는 파일명과 alt 를 붙인다
